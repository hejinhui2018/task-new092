# 骑马钉画册拼版台（Saddle-Stitched Imposition Desk）

一个完全运行在浏览器内的印前拼版预览工具：制作人员在送印前即可看清**每张印张正反面的页码位置、制版朝向、装订边、裁切线与出血区**，并逐页翻阅折叠成书后的真实页序，提前发现封底错位、背面倒置、缺页重页、出血不足等问题。

使用 React + TypeScript + Vite 实现，核心拼版算法为纯函数并配有单元测试，无后端、无外部服务，数据只保存在浏览器本地。

## 运行方式

```bash
# 1. 安装依赖（Node 18+）
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 运行测试（一次性）
npm test
#    或监听模式
npm run test:watch

# 4. 生产构建（先 tsc 类型检查，再打包到 dist/）
npm run build

# 5. 本地预览生产构建
npm run preview
```

## 功能说明

- **首屏内置 16 页产品手册**：标准 4 帖骑马钉书，最外帖配对为正面 `16 | 1`、背面 `2 | 15`，向内依次收敛。
- **左侧页面栏（阅读顺序）**
  - 拖动卡片调整页面顺序；
  - 增加 / 删除页面；
  - 编辑每页的印刷页码、四周出血量（mm）、标记来稿是否倒置 180°。
- **自动补白**：页数不是 4 的倍数时，在**封底（最后一页）之前**插入空白页（如 18 页 → 20 页，空白落在第 18、19 帖位，封底仍在最后），补白页在版面检查中以提示信息标出。
- **中间印张视图（按纸帖分层）**
  - 每张纸的**正面（外开面）与背面（内开面）**分开绘制；
  - 明确标注阅读序号、制版旋转角（0°/180°）、印刷页码；
  - 橙色粗条标示**装订边**，虚线四角为**裁切线（角线）**，外圈色带为**出血区**，出血不足 3mm 时变红；
  - 「↑ 头」标记制版时的页面头部方向。
- **长边 / 短边翻面切换（不只是文字标签）**
  - **长边翻面**（左右翻 · 书本式）：两槽左右并排，绕竖直折口翻面，四版全部正向；
  - **短边翻面**（上下翻 · 台历式）：两槽改为上下叠放，绕水平折口翻面，两个上槽制版旋转 180°（头对头拼版），装订边与折口方向同步改变。
  - 切换后背面的槽位排布、旋转角度、装订边立即重算重绘。
- **逐张折叠预演**：弹窗模拟成书翻阅（方向键 / 空格 / 进度条翻页，Esc 关闭），显示该页位于第几帖、正反面、槽位与印刷页码，并就地列出该页问题。
- **版面检查**：自动指出
  - 缺页（印刷页码断号）、重复页（同号出现多次）、倒置（来稿旋转 180°）、出血不足（< 3mm）、自动补白提示；
  - 点击「查看第 N 帖位」直接跳到折叠预演对应页。
- **本地持久化**：页面列表、翻面方式、预演是否打开及当前翻阅位置均保存在 `localStorage`（键 `saddle-stitch-desk:v1`），刷新或重开浏览器后继续；数据损坏时自动回退到内置示例。

## 拼版规则速查

设补白后总页数为 `n`（4 的倍数），由外向内第 `i` 帖（`i` 从 0 开始）：

| 面 | 槽位（长边 / 短边） | 页码（阅读序，0 基） |
|---|---|---|
| 正面 | 左 / 上 | `n - 1 - 2i` |
| 正面 | 右 / 下 | `2i` |
| 背面 | 左 / 上 | `2i + 1` |
| 背面 | 右 / 下 | `n - 2 - 2i` |

- 长边：四版制版均为 0°，装订边指向中缝（左槽在右沿、右槽在左沿）。
- 短边：两个上槽制版 180°、两个下槽 0°，装订边上槽在下沿、下槽在上沿（成品汇合为顶订折口）。

## 目录结构

```
src/
  types.ts                 领域模型（内容页/空白页/翻面方式/槽位）
  state.ts                 localStorage 持久化与内置示例回退
  App.tsx                  三栏布局与状态编排
  lib/
    imposition.ts          补白 + 骑马钉页码配对 + 翻面旋转（核心算法）
    fold.ts                折叠后阅读顺序（槽位 → 阅读页映射）
    diagnostics.ts         缺页/重页/倒置/出血/补白检查
    sample.ts              内置 16 页产品手册
    *.test.ts              核心算法单元测试（Vitest）
  components/              PageList / SheetCard / SlotView / PreviewModal / IssuesPanel
```

## 测试覆盖

`npm test` 运行 4 个测试文件、共 35 个用例，覆盖：

- 向上取整到 4 的倍数与封底前补白位置；
- 16 页标准骑马钉配对（16-1 / 2-15 起逐帖收敛）、每个页号恰好出现一次；
- 长边 / 短边翻面的槽位排布、制版旋转角、装订边差异；
- 折叠后阅读顺序连续、封面/封底/内帖物理位置正确；
- 缺页、重复页、倒置、出血不足、补白诊断；
- App 首屏 SSR 冒烟渲染。
