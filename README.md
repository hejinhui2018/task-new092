# 骑马钉画册拼版台（Saddle-Stitched Imposition Desk）

一个完全运行在浏览器内的印前拼版与装订配套工具：制作人员在送印前即可看清**每张印张正反面的页码位置、制版朝向、装订边、裁切线与出血区**，逐页翻阅折叠成书后的真实页序；印厂装订主管还能登记**各印刷批次折手的正反面合格数量、色批与质检状态**，实时算出**现存印张能装成多少本、短板折手与未配套余量**，并在输入交付目标后比较**补印哪几块版最省开机次数**。

使用 React + TypeScript + Vite 实现，核心拼版、成套分配与补印规划算法均为纯函数并配有单元测试，无后端、无外部服务，数据只保存在浏览器本地。

## 运行方式

```bash
# 1. 安装依赖（Node 18+）
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 运行测试（一次性）
npm test
#    或监听模式
npm run test:watch

# 4. 生产构建（先 tsc 类型检查，再打包到 dist/）
npm run build

# 5. 本地预览生产构建
npm run preview
```

## 功能说明

- **首屏内置 16 页产品手册**：标准 4 帖骑马钉书，最外帖配对为正面 `16 | 1`、背面 `2 | 15`，向内依次收敛。
- **左侧页面栏（阅读顺序）**
  - 拖动卡片调整页面顺序；
  - 增加 / 删除页面；
  - 编辑每页的印刷页码、四周出血量（mm）、标记来稿是否倒置 180°。
- **自动补白**：页数不是 4 的倍数时，在**封底（最后一页）之前**插入空白页（如 18 页 → 20 页，空白落在第 18、19 帖位，封底仍在最后），补白页在版面检查中以提示信息标出。
- **中间印张视图（按纸帖分层）**
  - 每张纸的**正面（外开面）与背面（内开面）**分开绘制；
  - 明确标注阅读序号、制版旋转角（0°/180°）、印刷页码；
  - 橙色粗条标示**装订边**，虚线四角为**裁切线（角线）**，外圈色带为**出血区**，出血不足 3mm 时变红；
  - 「↑ 头」标记制版时的页面头部方向。
- **长边 / 短边翻面切换（不只是文字标签）**
  - **长边翻面**（左右翻 · 书本式）：两槽左右并排，绕竖直折口翻面，四版全部正向；
  - **短边翻面**（上下翻 · 台历式）：两槽改为上下叠放，绕水平折口翻面，两个上槽制版旋转 180°（头对头拼版），装订边与折口方向同步改变。
  - 切换后背面的槽位排布、旋转角度、装订边立即重算重绘。
- **逐张折叠预演**：弹窗模拟成书翻阅（方向键 / 空格 / 进度条翻页，Esc 关闭），显示该页位于第几帖、正反面、槽位与印刷页码，并就地列出该页问题。
- **版面检查**：自动指出
  - 缺页（印刷页码断号）、重复页（同号出现多次）、倒置（来稿旋转 180°）、出血不足（< 3mm）、自动补白提示；
  - 点击「查看第 N 帖位」直接跳到折叠预演对应页。
- **本地持久化与撤销重做**：页面列表、翻面方式、折手库存、色批规则、锁定批次、交付目标、预演位置均保存在 `localStorage`（键 `saddle-stitch-desk:v2`），刷新或重开浏览器后继续；任何文档修改都可撤销 / 重做（按钮或 `Ctrl+Z` / `Ctrl+Y`，上限 80 步）；旧版 `:v1` 数据自动迁移（保留页面与翻面，库存从空开始，不虚构车间数据），数据损坏时回退到内置示例。

## 折手库存与补印决策

- **首屏内置配套示例**：16 页手册对应 4 帖，两个色批「晨雾蓝（四帖各 100 份）/ 暖沙金（四帖各 50 份，第 3 帖运输破损只剩 30 份）」，交付目标 150 本——现存可装 130 本，系统直接给出「重开 1 块版：第 3 帖 20 份」的最省候选。
- **库存登记（库存矩阵）**
  - 按「折手 × 印刷批次」登记**正面 / 背面合格数量**与质检状态（合格 / 待复检 / 报废）；
  - 每个印刷批次隶属一个**色批**，可新增色批与批次、删除批次（连带清理库存与锁定引用）；
  - 矩阵折手行与中间印张预览**双向联动高亮**（悬停即可定位对应印张）。
- **成套规则（参与分配，而非取最小值）**
  - 一本书需要每一折手各一份；单条库存可装数 = `min(正面合格, 背面合格)`，**正反面必须同批**；
  - 待复检不参与自动成套、报废为 0，正反面数量差作为单面富余单列；
  - 色批兼容三档：**仅同色批 / 指定色批对可混 / 任意混用**；不兼容的色批不会被配进同一本书；
  - 分配按确定的优先级（不混色批优先 → 色批种数少 → 色批/批次字典序）逐组成套，并在链式兼容（A-B、B-C 可混而 A-C 不可混）等结构下用多策略竞赛保证成套数最大；同一输入永远得到同一方案。
- **成套批次面板**：实时给出可装订本数（含已锁定数）、短板折手、每帖未配套余量，以及待复检 / 报废 / 正反面不齐的搁浅库存；每个自动成套组列出「第几帖来自哪个批次」，可整组或部分**锁定**；锁定后该部分印张优先预留，库存被改少时报告「锁定 X 本仅能满足 Y 本」，兼容规则改严时保留预留但标记冲突。
- **补印决策**
  - 输入交付目标后，枚举所有可行的「重开版组集合 × 补印色批」，逐份模拟补印后的成套结果并回减过印，求得每个组合的**最小补印量**；
  - 候选按 **开机版组数 → 补印印张数 → 剩余浪费** 排序，首条标记「最省开机」；
  - 每个候选解释：重开哪几块版、各多少份、补印色批、与哪些现存批次的余帖配套、共能装到多少本；
  - 「采用此方案」把补印品落为新的印刷批次（正反面库存同时入账），分配随即重算达标；
  - 无解时明确列出约束：哪一帖必须补印、哪条色批规则堵死了目标、有多少待复检库存复检后可能缩小补印范围。

## 拼版规则速查

设补白后总页数为 `n`（4 的倍数），由外向内第 `i` 帖（`i` 从 0 开始）：

| 面 | 槽位（长边 / 短边） | 页码（阅读序，0 基） |
|---|---|---|
| 正面 | 左 / 上 | `n - 1 - 2i` |
| 正面 | 右 / 下 | `2i` |
| 背面 | 左 / 上 | `2i + 1` |
| 背面 | 右 / 下 | `n - 2 - 2i` |

- 长边：四版制版均为 0°，装订边指向中缝（左槽在右沿、右槽在左沿）。
- 短边：两个上槽制版 180°、两个下槽 0°，装订边上槽在下沿、下槽在上沿（成品汇合为顶订折口）。

## 目录结构

```
src/
  types.ts                 领域模型（内容页/空白页/翻面方式/槽位）
  state.ts                 文档历史（撤销/重做）、v1→v2 迁移、localStorage 持久化
  App.tsx                  布局与状态编排（拼版区 + 装订配套区）
  lib/
    imposition.ts          补白 + 骑马钉页码配对 + 翻面旋转（核心算法）
    fold.ts                折叠后阅读顺序（槽位 → 阅读页映射）
    diagnostics.ts         缺页/重页/倒置/出血/补白检查
    inventory.ts           折手库存、色批兼容、确定性成套分配、锁定、补印候选枚举与排序
    sample.ts              内置 16 页产品手册 + 两色批一处短缺库存示例
    *.test.ts              核心算法单元测试（Vitest）
  components/              PageList / SheetCard / SlotView / PreviewModal / IssuesPanel
                           InventoryPanel / KittingPanel / ReprintPanel
```

## 测试覆盖

`npm test` 运行 6 个测试文件、共 68 个用例，覆盖：

- 向上取整到 4 的倍数与封底前补白位置；
- 16 页标准骑马钉配对（16-1 / 2-15 起逐帖收敛）、每个页号恰好出现一次；
- 长边 / 短边翻面的槽位排布、制版旋转角、装订边差异；
- 折叠后阅读顺序连续、封面/封底/内帖物理位置正确；
- 缺页、重复页、倒置、出血不足、补白诊断；
- **正反面同批取小值、待复检/报废/单面富余搁浅、色批 same/pairs/any 兼容、
  非最小值的分组成套、链式兼容多策略最优、锁定预留与缺口、冲突标记、
  补印候选的最小开机版组/印张/浪费排序与无解约束、采用后达标**；
- **撤销/重做变迁、历史上限、v1→v2 迁移、库存文档复活与字段容错**；
- App 首屏 SSR 冒烟渲染（拼版台 + 库存矩阵/成套/补印首屏联动）。
